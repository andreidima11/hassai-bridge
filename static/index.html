How to Connect

1

Install the Integration

Install the HASSAI Bridge custom integration in Home Assistant from the official repository.

https://github.com/andreidima11/hassai-bridge-ha

Go to HACS → Integrations → Custom repositories, paste the URL above and install.

2

Enter the API URL

When configuring the integration, enter the HASSAI Bridge server URL.

http://localhost:8899

Use the local IP of the machine running HASSAI Bridge, not localhost, so Home Assistant can reach it.

3

Create a User & API Key

Go to the Users tab above and create a user. Each user gets a unique API key — this allows the AI to remember things per person and track usage individually.

Copy the API key and paste it in the integration configuration in Home Assistant.

4

Set as Assistant

In Home Assistant, go to Settings → Voice assistants and select HASSAI Bridge as your conversation agent. That's it!

You can now talk to the AI from any dashboard, Assist pipeline, or automation.
